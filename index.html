🔧 如何把本页变成真正的"实时"网站

纯前端无法直接跨域抓取 WHO 数据（CORS 限制），推荐以下任一方案：

本页面 KPI 当前为演示快照：生产环境由 GitHub Actions 每 6 小时调用 fetch_data.py 生成 data.json，前端自动读取。
方案做法成本
① GitHub Actions 定时抓取（推荐）每 6 小时运行 Python 脚本，调用 WHO GHO OData API / OWID Grapher CSV（已开放 CORS）/ 中国 CDC 周报，生成 data.json 提交回仓库，前端读取免费
② 轻量后端代理Node/Python 后端定时拉取 WHO、ECDC、HealthMap，暴露 /api/live 给前端低
③ 托管 + 手动更新直接部署本 HTML 到 GitHub Pages / Vercel，每月根据 WHO 报告手动更新数据免费
// 前端接入示例（fetch 你的 data.json）
async function fetchLive(){
  const r = await fetch('data.json?ts='+Date.now());
  const d = await r.json();
  render(d); // 用真实数据替换演示数值
}
setInterval(fetchLive, 30*60*1000); // 每30分钟

免责声明：本页面为公共卫生数据可视化演示，仅用于信息展示，不构成医疗建议。所有数据以 WHO、各国卫生部门及中国疾病预防控制中心官方发布为准。各来源统计口径、报告延迟与修订机制不同，跨来源比较请谨慎。
